## 2026-11-02 — HTTP POST 403/405 teşhisi ve test onarımı

Mac gerçek HTTP testinde önceki commit `d74456a` üzerinde **54/54 gerçek PostgreSQL testi**, **3/3 HTTP kaynak koruması**, **TypeScript** PASS; fakat HTTP son adımda `POST` için beklenen `405` yerine `403` geldi ve `EFT04C2_EXIT=1` oldu.

Kök neden: `proxy.ts`, `/api/*` mutasyonlarında `Origin` zorunlu kılar. Testte POST `Origin` içermiyordu; proxy doğru şekilde `403` döndürdü ve GET-only route'a ulaşılmadı. **Güvenlik gevşetilmedi.** Yeni test iki ayrı güvenlik sınırını kontrol eder:

1. `POST` + eksik `Origin` → **403**, proxy aynı-origin koruması.
2. `POST` + doğru loopback `Origin` → **405**, salt-okunur Next.js route.

Her iki denemeden sonra `payments` ve `eft_reconciliation_reviews` satır sayılarının değişmediği doğrulanır. Bu düzeltme yalnız test kodundadır; API, proxy, DB migration, banka hesabı, Production/Preview değiştirilmedi. **Yeni Mac sonucu henüz alınmadı.**
