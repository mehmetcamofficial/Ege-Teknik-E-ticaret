# Ege Teknik E‑Ticaret

GREE klima satışı, keşif, montaj, bakım, onarım, yedek parça ve ikinci el ürün yönetimi için geliştirilen tam kapsamlı web mağazası.

## Özellikler

- Canlı ürün ve stok yönetimi
- Güvenli yönetici girişi
- Servis ve keşif talepleri
- Sipariş yönetimi
- Ege Bölgesi hizmet sayfaları
- SEO ve yapay zekâ arama görünürlüğü için içerik yapısı

Proje Kaizen ve Clean Code yaklaşımıyla fazlar halinde geliştirilmektedir.
